# Feedback Management System

A Django-based web application that allows students to submit feedback about their teachers.

## Features

- **Student Login & Feedback Submission** with interactive 5-star rating
- **Admin Dashboard** with statistics (students, teachers, feedback)
- **Student Management** (Add, Delete)
- **Teacher Management** (Add, Delete)
- **Feedback Viewing** with rating and description
- **Duplicate Prevention** — Students can only submit feedback once per teacher
- **Role-Based Access Control** — Students and Admins see different pages
- **Mobile Responsive Design**

## Tech Stack

- **Backend:** Django 6.1
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Database:** SQLite (development), PostgreSQL (production)
- **Deployment:** Railway / Render
